# R0 性能基线 (2026-11-13, 多次采样)

机器: Intel(R) Core(TM) Ultra 5 125H, 单线程。
Julia 1.12.0 (threads=1), NESSi 2.0.0 (Release, gcc)。
采样: Julia quick ×4 (run1..run4), Julia release ×2, NESSi quick ×3。
口径: Julia = tutor/profiles.jl 预热后第二次运行计时 (frozen quick 参数);
NESSi = kbref 生成器同参数 (/usr/bin/time wall)。
**R10 对比协议: 双方均取 >=4 次采样的中位数** (Julia 单次涨落可达
±40%, 见下表; NESSi ±10%)。

## 结论

- 中位数口径下 Julia 版整体比 NESSi 慢约 2.1x, 逐项 1.6..2.7x;
  单次最好成绩 (run1) 曾给出 1.61x 总比 —— 多次采样是必要的。
- Rust 版优化空间参考: 逐项对标 NESSi 中位数即满足 D13 第二句;
  对标 Julia 中位数 (快于) 为第一验收。
