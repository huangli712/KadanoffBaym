## 口径说明

- Julia 基线 = R0 产出的 bench/baseline-julia-{quick,release}-20261113*.toml
  (进程内计时, 预热一次 + 计时第二次)。
- **Julia 的 quick 与 release 套件运行的是相同的 quick 网格参数**
  (tutor/profiles.jl 的 p5run_args 硬编码 `--profile quick`; 两档仅
  环境变量与预算断言不同), 故两行都可直接与本表对比。
- Rust = examples/bench (子进程计时, stdout 丢弃, 预热一次 + 计时两次取
  第二次; 进程生成开销 ~2ms 已计入, 对 0.04s+ 的 entry 影响可忽略)。
- NESSi 中位 = baseline-nessi-quick-20261113.txt 两次重复的中位数。
- 补充: Rust 在 TOML 的 [profile.release] 大网格档 (nt=200+ 等) 全套
  451.7s 跑通 (bench/rust-release-20261114.toml), 作为压力数据; Julia/
  NESSi 基线无同网格数据, 不做对比。
